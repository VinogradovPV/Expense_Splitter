# Руководство пользователя Expense Splitter

## Начало работы

Установите приложение и запустите desktop GUI:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\run-gui.ps1
```

GUI — основной пользовательский интерфейс. Он автоматически создаёт недостающие файлы в `data/`.

## Покупки

На вкладке `Покупки` доступны добавление, редактирование, детали и защищённое удаление.

- Участников можно выбрать галочками или ввести через запятую.
- Категорию можно выбрать из ComboBox, отметить в checklist или ввести вручную. Новая категория
  сохраняется только после подтверждения.
- Открытая покупка редактируется обычным образом.
- Закрытая покупка не редактируется и не удаляется, чтобы сохранить историю периода.
- Удаление open-покупки требует `DELETE_PURCHASE` и создаёт backup.

Фильтры: `open/settled/all`, категория, даты и часть названия. Заголовки `Дата`, `Сумма`,
`Категория`, `Плательщик` управляют сортировкой.

## Текущие расчёты

Scope `open` — основной режим: закрытые покупки не участвуют в балансах и переводах. Кнопка
`Показать все с историей` переключает отображение на scope `all` без изменения данных.

## Периоды взаиморасчётов

1. Выполните `Preview закрытия`.
2. Проверьте число покупок, сумму и переводы.
3. Нажмите `Закрыть период и обнулить текущие взаиморасчёты`.
4. Подтвердите операцию.

Покупки не удаляются: они помечаются закрытыми, а новые расчёты начинаются по open-покупкам.
`Детали периода` показывает snapshot; `Переоткрыть период` возвращает его покупки в scope `open`.

## Аналитика и отчёты

Выберите период `month`, `quarter` или `year`, заполните соответствующие поля и выберите формат:
`markdown`, `csv`, `png`, `html`, `xlsx` или `all`.

После генерации доступны:

- `Открыть папку отчета`;
- `Открыть HTML`;
- `Открыть XLSX`;
- `Открыть Markdown`.

HTML полностью offline и использует локальные PNG. XLSX содержит десять листов, фильтры,
freeze panes, числовые денежные значения и PNG на листе Charts. Статус последнего отчёта
показывается под кнопками.

## Данные и обслуживание

- `Открыть папку data` и `Открыть папку reports` открывают локальные каталоги.
- `Проверить данные` читает YAML и показывает число покупок.
- `Создать backup данных` копирует все YAML в `data/backups/<timestamp>/`.
- `Сбросить тестовые данные` требует `RESET_TEST_DATA`, создаёт backups и очищает только покупки и
  периоды. Участники, группы и категории сохраняются.

Reset-test не заменяет закрытие периода: close сохраняет историю, reset физически очищает тестовые
покупки и периоды.

## CLI

CLI полезен для автоматизации:

```powershell
expense-splitter --help
expense-splitter init
expense-splitter balances --scope open
expense-splitter settle --scope open
expense-splitter settlement-period --help
expense-splitter analytics --help
```

Подробности об аналитике и периодах находятся в [ANALYTICS.md](ANALYTICS.md) и
[SETTLEMENT_PERIODS.md](SETTLEMENT_PERIODS.md).
