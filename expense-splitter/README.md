# Expense Splitter

Expense Splitter — это CLI-приложение на Python для учета совместных покупок и распределения расходов между участниками. Оно позволяет легко фиксировать чеки, рассчитывать индивидуальные доли, определять чистые балансы и находить минимальное количество переводов для взаиморасчетов.

## Особенности

*   **Учет участников и групп:** Настройка списков людей и часто используемых групп (например, "809 кабинет", "Кофе").
*   **Фиксация покупок:** Добавление информации о чеках с указанием плательщика, суммы, даты, участников и категории.
*   **Точные расчеты:** Использование типа `Decimal` для предотвращения ошибок округления, характерных для `float`. Остатки от деления копеек корректно распределяются.
*   **Минимизация переводов:** Жадный алгоритм для расчета минимального количества транзакций, необходимых для закрытия всех долгов.
*   **Отчетность:** Генерация подробных отчетов в формате Markdown со сводкой балансов, списком покупок и необходимыми переводами.
*   **Хранение данных:** Простые и читаемые YAML-файлы для хранения состояния.

## Установка

Для установки проекта и его зависимостей рекомендуется использовать `uv` или `pip` в виртуальном окружении.

```bash
# Клонирование репозитория
git clone <repository_url>
cd expense-splitter

# Установка с помощью pip
pip install -e .

# Для разработки и тестирования
pip install -e ".[dev]"
```

## Использование

После установки будет доступна команда `expense-splitter`.

### Инициализация

Создание начальных файлов конфигурации в директории `data/`:

```bash
expense-splitter init
# С примерами данных:
expense-splitter init --with-examples
```

### Добавление покупки

```bash
expense-splitter add-purchase "Кофе" 1200.00 "Павел" --group "Кофе" --category "Напитки"
# Или указать конкретных участников:
expense-splitter add-purchase "Чай" 300.00 "Максим" --participants "Максим, Елена"
```

### Просмотр данных

```bash
# Список всех покупок
expense-splitter list-purchases

# Текущие балансы (кто в плюсе, кто в минусе)
expense-splitter balances

# Необходимые переводы для закрытия долгов
expense-splitter settle
```

### Генерация отчета

```bash
# Создаст файл reports/report.md
expense-splitter report
```

## Разработка

Для запуска тестов используйте `pytest`:

```bash
PYTHONPATH=src pytest tests/ -v
```

## Структура проекта

*   `src/expense_splitter/models.py` - Dataclasses для основных сущностей.
*   `src/expense_splitter/storage.py` - Работа с YAML-файлами.
*   `src/expense_splitter/calculator.py` - Логика расчета долей и балансов.
*   `src/expense_splitter/settlement.py` - Алгоритм минимизации переводов.
*   `src/expense_splitter/cli.py` - Интерфейс командной строки (Typer).
*   `src/expense_splitter/reporting.py` - Генерация Markdown отчетов.
