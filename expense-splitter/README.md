# Expense Splitter

Expense Splitter — это удобное кроссплатформенное приложение для учета совместных покупок и распределения расходов между участниками. Оно позволяет легко фиксировать чеки, рассчитывать индивидуальные доли, определять чистые балансы и находить минимальное количество переводов для взаиморасчетов.

## Для кого этот проект?

Этот проект предназначен для групп друзей, коллег, соседей или семей, которые регулярно совершают совместные покупки и хотят легко и справедливо распределять расходы. Если вы устали от ручных расчетов и хотите автоматизировать процесс взаиморасчетов, Expense Splitter — это то, что вам нужно.

## Что умеет приложение?

*   **Учет участников и групп:** Настройка списков людей и часто используемых групп (например, "809 кабинет", "Кофе").
*   **Фиксация покупок:** Добавление информации о чеках с указанием плательщика, суммы, даты, участников и категории.
*   **Точные расчеты:** Использование типа `Decimal` для предотвращения ошибок округления, характерных для `float`. Остатки от деления копеек корректно распределяются.
*   **Минимизация переводов:** Жадный алгоритм для расчета минимального количества транзакций, необходимых для закрытия всех долгов.
*   **Отчетность:** Генерация подробных отчетов в формате Markdown со сводкой балансов, списком покупок и необходимыми переводами.
*   **Хранение данных:** Простые и читаемые YAML-файлы для хранения состояния.
*   **Кроссплатформенность:** Работает на Windows, Linux и macOS.
*   **Удобный UX Launcher:** Интерактивное меню для пользователей, предпочитающих не работать с командной строкой напрямую.

## Быстрый старт

### Для Windows (PowerShell)

1.  Скачайте последний релиз с [GitHub Releases](https://github.com/YOUR_GITHUB_USERNAME/expense-splitter/releases).
2.  Распакуйте архив в удобное место (например, `C:\ExpenseSplitter`).
3.  Откройте PowerShell в этой папке и запустите установщик:
    ```powershell
    .\scripts\install.ps1
    ```
4.  Запустите интерактивный лаунчер:
    ```powershell
    .\scripts\run-launcher.ps1
    ```

### Для Linux/macOS (Bash)

1.  Скачайте последний релиз с [GitHub Releases](https://github.com/YOUR_GITHUB_USERNAME/expense-splitter/releases).
2.  Распакуйте архив в удобное место (например, `~/ExpenseSplitter`).
3.  Откройте терминал в этой папке и запустите установщик:
    ```bash
    ./scripts/install.sh
    ```
4.  Запустите интерактивный лаунчер:
    ```bash
    ./scripts/run-launcher.sh
    ```

## Использование

### UX Launcher

Для пользователей, которым удобнее работать с интерактивным меню, доступен UX Launcher. Он предоставляет простой способ выполнять основные операции без запоминания команд CLI.

*   На Windows:
    ```powershell
    .\scripts\run-launcher.ps1
    ```
*   На Linux/macOS:
    ```bash
    ./scripts/run-launcher.sh
    ```

### Командная строка (CLI)

Для продвинутых пользователей и автоматизации доступны следующие команды:

*   На Windows:
    ```powershell
    .\scripts\run-cli.ps1 --help
    ```
*   На Linux/macOS:
    ```bash
    ./scripts/run-cli.sh --help
    ```

Основные команды:

*   **`init`**: Инициализация файлов данных. Используйте `--with-examples` для создания примеров.
*   **`add-purchase`**: Добавление новой покупки.
*   **`list-purchases`**: Просмотр всех покупок.
*   **`balances`**: Отображение текущих балансов участников.
*   **`settle`**: Расчет минимальных переводов для закрытия долгов.
*   **`report`**: Генерация подробного Markdown-отчета.

Подробное описание всех команд CLI доступно в [INSTALLATION.md](docs/INSTALLATION.md) и через `expense-splitter --help`.

## Первый сценарий использования

1.  **Инициализация проекта:**
    ```bash
    expense-splitter init --with-examples
    ```
    Это создаст начальные файлы `data/participants.yaml` и `data/purchases.yaml` с примерами данных.

2.  **Добавление новой покупки:**
    ```bash
    expense-splitter add-purchase "Ужин в ресторане" 2500.00 "Анна" --participants "Анна, Борис, Вера" --category "Еда"
    ```

3.  **Просмотр текущих балансов:**
    ```bash
    expense-splitter balances
    ```

4.  **Расчет оптимальных переводов:**
    ```bash
    expense-splitter settle
    ```

5.  **Генерация отчета:**
    ```bash
    expense-splitter report --output reports/my_report.md
    ```
